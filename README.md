# M320-Projekt-kw18
Anleitung Drecksau:
Ziel des Spieles ist es, alle Schweine schlammig zu machen.
Zu Beginn erhält jeder Spieler Schweinekarten, wobei sich die Anzahl Karten nach den Anzahl Spielern richtet. Danach beginnt der jüngste Spieler und legt einer seiner Karten. Entweder wendet er diese an einem seiner Schweine an oder legt diese offen neben den Stapel hin. Dann ist der nächste Spieler dran. Es wird im Uhrzeigersinn gespielt. Der Spieler darf sich auch dafür entscheiden, die zu legende Karte wieer in den Stapel zurückzulegen. Danach zieht der nächste Spieler eine Karte vom Nachziehstapel. Sollte ein Spieler eine Karte nicht spielen können, da er beispielsweise eine Blitzableiterkarte zieht, jedoch keinen Stall hat, so darf er die Karte den Mitspielern zeigen, zurück in den Stapel legen und drei neue Karten nachziehen.

Die Karten:

Matschkarte: Das eigene Schwein wird zur "Drecksau", der Spieler ruft dabei laut "Drecksau" und dreht seine Schweinekarte um.
Regenkarte: Wenn diese gespielt wird, werden alle Schweine, auch die eigenen, welche nicht in einem Stall sind, wieder sauber.
Stallkarte: Diese Karte kann an eine eigene Schweinekarte (sauber oder dreckig) gelegt werden. Dieses Schwein ist dann vor dem Regen geschützt.
Blitzkarte: Damit kann ein Mitspieler den Stall eines anderen Mitspielers abfackeln. Dieser muss dann seine Stallkarte wieder entfernen. Achtung: Damit kann man auch die Bauer-ärgere-dich-Karte entfernen!
Blitzableiterkarte: Mit dieser Karte ist ein Stall gegen die Blitzkarte geschützt.
Bauer-schrubbt-die-Sau-Karte: Damit kann man eine Sau eines Mitspielers wieder sauber machen. Der Spieler ruft dabei "ich mach dich wieder sauber" Diese Karte kann auch eingesetzt werden wenn sich eine Drecksau in einem Stall befindet!
Bauer-ärgere-dich-Karte: Wer bereits einen Stall vor sich hat, kann diese Karte einsetzen. Die Sau ist nun vollkommen geschützt. Die Karte darf nur eingesetzt werden, wenn sich eine Drecksau im Stall befindet!
